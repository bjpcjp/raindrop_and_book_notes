Introduction

As an open source machine learning library, PyTorch has been gaining more and more popularity among artificial intelligence (AI) researchers for various applications, including computer vision and natural language processing. As its primary developer — Facebook AI Research (FAIR) has noticed the limited functionalities for processing 3D (i.e., 3-dimensional) data in PyTorch and other available toolkits, and thus they developed the PyTorch3D framework that aims to facilitate the innovative research in 3D deep learning field.

There are three key features for this framework, including its data structure using meshes, operations of these meshes, and a differentiable renderer. These features are introduced below.
