Why Snippets Matter

I am a huge advocate for snippets of code to create faster cycles of iteration over traditional machine learning pipelines. Pytorch has been an important part of my Machine Learning tool stack for a while now, so I decided to write this post to share some of my favorite code snippets to help you with your Pytorch models.

1. Printing the Pytorch version

import torch
print(torch.version.__version__)# Output1.7.1

2. Creating tensor from nested list of ndarray

example_list = [1,2,3]
x = torch.tensor(example_list)
print(x)# Outputtensor([1, 2, 3])

3. Cloning a tensor

y = x.clone()
print(y)# Outputtensor([1, 2, 3])

4. Getting Size and Shapes

x = torch.randn((10,10))
print(x.size())
# or
print(x.shape)# Output
