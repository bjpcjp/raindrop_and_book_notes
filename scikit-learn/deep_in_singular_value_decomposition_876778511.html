Introduction

There are often times when working in Data Science where we might come across a feature that is very difficult to interpret by a computer. This is often because the dimensions of the data are much too large for a computer to impute. This can be problematic because it is very hard to observe hundreds of dimensions of a feature. This is the case for both humans, and computers of course.

Fortunately, for this problem there is a solution. In the world of Data Science, it is quite common to use something called decomposition in order to make these values a bit more legible by both statistics, and in turn machine-learning and analytical strategies. In most cases, programmers will use a decompostion strategy called Singular Value Decompisition. However (SVD), there are also other solutions that can be used such as Random Projection. Out of these two solutions, SVD is much more widely used, as random projection needs suitable dimension space between points and can sometimes be problematic on some features as a result.
