Streamlit documentation

Streamlit is an open-source Python framework for data scientists and AI/ML engineers to deliver dynamic data apps with only a few lines of code. Build and deploy powerful data apps in minutes. Let's get started!

How to use our docs

What's new

palette

Chart colors with theming

The color parameter of simple charts supports the basic color palette configured with theming.

gradient

Diverging chart colors

Use theme.chartDivergingColors to set default diverging colors for Plotly, Altair, and Vega-Lite charts.

emoji_emotions

Icons and emojis in st.logo

st.logo now supports Material icons and emojis in addition to images.

link

Configure error help links

Control the display of error help links with the new client.showErrorLinks configuration option.

key

Stable widget identity

More widgets now use only their key for identity, preventing resets when changing other parameters.

integration_instructions

ASGI entry point & Starlette support

Streamlit supports an experimental ASGI entry point with Starlette for custom HTTP routes, middleware, and FastAPI integration.
