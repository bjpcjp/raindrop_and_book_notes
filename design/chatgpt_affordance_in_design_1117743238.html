Affordance is a concept from design and psychology that refers to the possible actions that an object or environment allows a user to perform, based on how it looks or is structured.

Key Points:

  1. Definition (Design Context):

    An affordance is a property or feature of an object that suggests how it should be used.

  2. Origin:
    Coined by psychologist James J. Gibson (1977) in ecological psychology, and later popularized in design by Don Norman in The Design of Everyday Things (1988).

  3. Types:

    • Perceived affordance: What a user thinks an object allows them to do (e.g., a button that looks clickable).

    • Actual affordance: What the object really allows (e.g., a button that’s actually clickable).

    • False affordance: When the perceived affordance doesn't match the actual function (e.g., a decorative element that looks like a button but isn’t).

    • Hidden affordance: A possible action not visible or suggested by the object's appearance (e.g., swiping on a photo to see the next one without visible controls).

  4. Examples:

    ObjectAffordance
    Door handleAffords pulling
    Flat plate on doorAffords pushing
    ScrollbarAffords dragging to scroll
    Toggle switchAffords flipping between two states

  5. Relevance in UI/UX Design:
    Designers use affordances to make interfaces intuitive. For example, buttons should look like they can be clicked, and input fields should look like they can be typed into.
