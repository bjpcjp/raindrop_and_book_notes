Databricks MLflow is an open-source platform to manage Machine Learning Lifecycle. In layman’s terms, it can track and store data, parameters, and metrics to be retrieved later or displayed nicely on a web interface. This is useful in experimentations or A/B testing where tracking hyperparameters and evaluation metrics is important for transparency and reproducibility. MLflow can also enable central model governance and encourage collaboration since it is a centralized model repository.

This article will touch on the components and terminologies used in MLflow, Python examples on how to set up, track, and query with MLflow, and finally how to launch the MLflow web interface.
