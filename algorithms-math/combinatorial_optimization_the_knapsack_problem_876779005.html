Problem Description

The Knapsack problem

This problem is called the knapsack problem, because one would encounter a similar problem when packing items into knapsack, while trying to optimize, say, weight and value of the items packed in.

So, given a list of strings:

r1 = ['001', '11', '01', '10', '1001']

and given a container that can accommodate at most 5 zeros and 5 ones.

m = 5
n = 5

What is the maximum number of strings I can pack into the container?

one choice would be:

c1 = ['001', '1001', '11']

In this case we have packed in 3 strings, and used up 4 zeros and 5 ones, is this the best we can do?
