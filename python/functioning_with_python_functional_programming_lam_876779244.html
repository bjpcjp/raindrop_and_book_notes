Lambda

These are anonymous functions with a single expression that gets evaluated. There can be more than one arguments to the lambda function but the expression that gets evaluated would only be one. 

func = lambda x: x ** 2
 
func(13)
 
Output: 169

Passing the lambda as an argument to another function

The lambda function can also be passed as an argument to another function. 

def test_func(fn, x):
    return fn(x)
 
func = lambda x: x // 2
 
test_func(func, 101)
 
Output: 50

Using lambda functions for sorting

The sorted() function is used to sort the values inside an iterable. By default, the pack of values are sorted in alphabetical or numerical order but using lambda functions we can go a step further with customizations. 

 
l = ['af', 'be', 'cd']
 
print(sorted(l))
 
print(sorted(l, key=lambda x: x[1]))
 
Output: 

['af', 'be', 'cd']
['cd', 'be', 'af']

Here we are able to sort the list considering the 2nd alphabet of every element. The lambda function passed as a named argument is used to decide the order of the sorting. Each element of the iterable goes through the expression inside the lambda function and then the sorted function acts on the resultant.

Map

It is used to apply a function to an iterable. Map function returns a map iterable object, which can be converted to a list or set or be yielded through generators. The logic behind returning an iterable object is that the whole result doesn't reside in memory but instead we can yield objects one by one.

Declaration - map(function, *iterables)

(hope * here has a clear meaning for us now, if not please read my article on * and **) 

print(list(map(lambda x: x ** 2, [1,2,3])))
      
print(list(map(lambda x,y : x ** y, [1,2,3], [3,4,5])))

Output: 

[1, 4, 9]
[1, 16, 243]

Here we are using lambda but we can also use regular functions and pass their name instead. Important to note that we are converting the result of the map to a list.

Filter

As the name suggests, it applies a function on each element of the iterable but returns an iterator with only those elements for which function return True.

Declaration - filter(function, iterable)

We can pass only a single iterable in this case, unlike map. 

def even(elem):
    if elem % 2 == 0:
        return True
    else:
        return False
   
list(filter(even, [1,2,3,4,5,6]))

Output: [2, 4, 6]

Zip

It is used to aggregate multiple iterators in a tuple. It is more like one to one mapping of multiple iterators.

As we can see from the diagram above, both list when used inside zip function (can be of varying lengths) resultant tuples are obtained with elements from each iterator. 

list(zip([1,2,3,4], ['a', 'b', 'c']))

Reduce

As the name suggests it reduces or we can say decomposes the iterable into a single value by applying a function repeatedly on intermediate results.

Declaration - functools.reduce(function, iterable[, initializer]) 

from functools import reduce


def sum_elem(a, b):
    print('a - ', a, ' , b - ', b)
    return a + b


reduce(sum_elem, [1, 2, 3, 4])

Output: 
a -  1  , b -  2
a -  3  , b -  3
a -  6  , b -  4

10

We can see that reduce function passes the intermediate value as the first argument to the function and the next value in the sequence as the second value. In this way, we are able to decompose to a single value at the end.

Accumulate

Much like the reduce function only that it also returns the intermediate values as the output instead of just returning the single decomposed value.

Declaration - itertools.accumulate(iterable[, func, *, initial=None]) 

from itertools import accumulate


list(accumulate([1, 2, 3, 4], lambda a, b: a + b))

Output: 
[1, 3, 6, 10]
