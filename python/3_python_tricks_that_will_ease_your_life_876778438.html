Python is the go-to language for people working in the data science ecosystem. There are several reasons why Python is the predominant choice in the field such as the easy-to-learn structure, simple syntax, and the rich selection of third party libraries.

What I like most about Python is how it simplifies certain tasks. In this article, I will share 3 tips or tricks that I find quite practical. I have used them at my job and I think you might find them useful as well.

I would like to emphasize that these tricks are not some advanced Python features. In fact, they can be considered as basic operations. However, they come in handy for certain tasks.

1. String interpolation

The first one is about string interpolation which allows for manipulating strings by using variable names. We use them a lot with the print function for debugging the code or confirming the results.

A typical use case for string interpolation is to create file paths that contain information based on some variables. For instance, I use string interpolation for integrating date information into the file paths.
