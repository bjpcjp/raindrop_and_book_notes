Installation

If you are on Windows make sure to install Ghostscrip from here. You can still install camelot without the prior installation of Ghostscript. But we will run into errors when trying to use camelot.

conda install -c conda-forge camelot-py

or

pip install "camelot-py[cv]"

or

git clone https://www.github.com/camelot-dev/camelot
cd camelot
pip install ".[cv]"

Usage

We will first import camelot and then provide the file path of the pdf file. The read_pdf comes with many parameters we can explore. The sample pdf used for the below example is located here.

import camelot
tables = camelot.read_pdf('https://trade.indiabulls.com/pdf/NSE_Holidays_Equity.pdf')

Numbers of tables: Prints the number of tables extracted. The above article has 2 tables.

tables.n
>>> 2
