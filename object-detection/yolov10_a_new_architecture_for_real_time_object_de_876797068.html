Yesterday (24/05/2024) marked the launch of the new state-of-the-art architecture named YOLOv10 [1], representing the cutting-edge in real-time object detection. Developed by researchers from Tsinghua University, it addresses issues previous networks faced, bringing a host of improvements over previous models. One of the key enhancements is the backbone, which utilizes an enhanced version of CSPNet [2] to optimize gradient flow, reduce computational redundancy, and minimize gradient drop across the network. Additionally, PAN layers [3] have been added to the network's Neck, capable of aggregating different scales for feature extraction to be passed to the Head of the model. Furthermore, there's the inclusion of a Partial Self-Attention (PSA) module [4], designed to enhance global representation learning with minimal overhead. A crucial change is the elimination of NMS [5], which was previously a bottleneck in networks. This leads to reduced latency and improved efficiency, achieved through the One-to-many Head structure, generating a vast amount of predictions per object as input traverses the network, thus facilitating greater feature extraction and enhancing model learning. The following example showcases an implementation using the YOLOv10-n and YOLOv10-x networks with their pre-trained weights applied for inference in a football match, a complex scenario with substantial movement. The aim is to demonstrate and compare the results obtained between both architectures for real-time detection and classification. The code was executed on Google Colab utilizing a Tesla T4 GPU, providing 15 GB of GPU during execution. The YOLOv10-n model averaged 11.1ms per frame for video processing and 5 seconds in total for prediction. In comparison, YOLOv10-x, with the same settings, averaged 24.9ms per frame and 11 seconds in total for video processing, resulting in approximately 120% increase in total execution time. Despite the increase in execution time, YOLOv10-x produced more stable bounding boxes and generally had higher confidence in detections. It also managed to identify more players and the football for longer periods. However, in less complex situations, confidence in measurements tended to decrease, which is ironic as YOLOv10-x appears to handle complex predictions better but exhibits lower confidence in simple measurements.
